# Spotify Playlist Downloader

A sleek and modern Flutter application that allows users to download songs from a Spotify playlist by simply pasting the playlist URL. The app is built entirely with Flutter and communicates with a backend API to fetch and download the songs.

## ✨ Features

- 🎵 Paste any Spotify playlist URL  
- ⬇️ Download all songs in a playlist with one click  
- ⚡️ Fast and intuitive user interface  
- 📱 100% built with Flutter  
- 🌐 Communicates with an external API for song data
